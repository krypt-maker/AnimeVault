# AnimeVault v2

## Run locally
1. Install Node.js LTS.
2. Open this folder in File Explorer.
3. Click the address bar, type `cmd`, and press Enter.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown by Vite (usually http://localhost:5173).

## Features
- Starter catalogue with popular anime titles.
- Search and genre filtering.
- Online top-anime catalogue via the public Jikan API (internet required).
- Anime detail cards and browser-stored watchlist.
- Demo admin form for adding/removing local catalogue entries.
- Responsive dark blue design.

## Important notes
- This is a front-end demo. The watchlist and admin-added titles are stored only in the current browser using localStorage.
- The demo admin panel is not secure and must not be used as a public production admin system.
- No anime episode files are hosted. Only add links where distribution is authorised by the copyright holder.
- The online catalogue depends on the public Jikan API and may be temporarily unavailable.
